# 꼬마 공주 키우기 — 설계 문서

작성일: 2026-10-10
시안: `docs/superpowers/mockups/princess-mockup.html` (캐릭터 고르기 / 메인 / 전투 — 승인된 그림체)

## 개요

프린세스메이커 2·3을 참고한 **키우기 + 모험 RPG**. 공주 후보 소녀 한 명을 골라 3년(36달) 동안
매달 스케줄(공부·아르바이트·휴식·무사수행)을 정해 키우고, 무사수행에서는 적과 **턴제 전투**를 한다.
상점에서 산 장비를 장착하면 **캐릭터 모습이 바로 바뀐다**. 3년 뒤 능력치와 모험 결과에 따라 약 12종 엔딩.

대상: 제작자의 딸(글 잘 읽음). 한국어 UI. 플레이 1회 약 1시간, 매달 자동 저장.

## 목표 / 비목표

**목표**
- 승인된 시안 수준의 화사한 파스텔 그림체 (코드로 그린 SVG, 외부 이미지 없음)
- 캐릭터 4명 선택 + 이름 짓기
- 장비 4칸(무기/옷/모자/액세서리), 장착 시 외형 변화
- 매달 스케줄 → 결과 연출 → 이벤트 → 자동 저장
- 무사수행: 지역 4곳, 칸 이동 보드 + 턴제 전투 + 보스
- 재미있는 메인 스토리(별빛 왕관) + 랜덤/계절 이벤트 + 엔딩 도감
- 웹오디오 배경음악·효과음 (외부 파일 없음)

**비목표 (YAGNI)**
- 세로 모드 스마트폰 최적화 (PC·태블릿 가로 화면 기준. 터치 클릭은 그대로 동작)
- 저장 슬롯 여러 개 (자동 저장 1개 + 엔딩 도감만)
- 다국어, 서버, 계정

## 이야기

### 세계와 등장인물
- **꽃잎 왕국**: 꽃과 요정이 사는 작은 왕국. 왕국을 지키는 **별빛 왕관**에는 별 보석 4개가 박혀 있다.
- **요정 루루**: 공주 곁에서 조언해 주는 수다쟁이 꼬마 요정(원작의 집사 큐브 역할). 화면 왼쪽 위 말풍선의 주인.
- **플레이어**: 공주의 보호자. 루루와 함께 공주의 매달 할 일을 정해준다.
- **공주 후보 4명**: 루비(용감, 힘·체력↑) / 사파이어(똑똑, 지능·마력↑) / 로즈(상냥, 매력·기품↑) / 에메랄드(활발, 체력·매력↑)
- **심술 마왕 그르릉**: 구름 위 탑에 사는 마왕. 사실은 100년 동안 아무도 놀아주지 않아 심술이 난 외톨이.
- 조연: 고양이 떠돌이 상인 **냥냥이**, 이웃 나라 **레오 왕자**, 숲속 **마녀 할머니 모모**, 길 잃은 강아지 **콩이**

### 줄거리
1. **프롤로그 (1달째)**: 어느 봄밤, 심술 마왕 그르릉이 "놀아주지 않는 왕국 따위!" 하며 별빛 왕관의 별 보석 4개를
   훔쳐 왕국 네 곳에 숨긴다. 왕관이 빛을 잃자 왕국에 조금씩 회색 구름이 낀다.
   별똥별을 따라 날아온 요정 루루가 "별이 고른 아이"인 주인공을 찾아온다.
   "3년 뒤 **별빛 축제**까지 보석을 모두 찾아서 왕관을 되살리자! 그 전에 먼저 튼튼하고 멋진 공주가 되어야 해!"
2. **1년차**: 반짝반짝 숲의 **초록 별(용기)**. 숲을 지키던 대왕 버섯 뭉게가 보석 때문에 심술이 났다. 이기면 정신을 차리고 사과한다.
3. **2년차**: 수정 동굴의 **파란 별(지혜)**. 수정 골렘 또각이가 "수수께끼를 못 풀면 못 지나가!" 하며 길을 막는다.
   얼음 성의 **하얀 별(상냥함)**. 눈의 여왕 프로스티는 외로워서 성을 얼려 버렸다. 이기면 친구가 되어 겨울을 녹인다.
4. **3년차**: 보석 3개를 모으면 하늘에 **구름 계단**이 생겨 마왕의 탑이 열린다. 마왕 그르릉과 결전.
   이긴 뒤 그르릉이 울먹이며 고백한다: "아무도… 나랑 안 놀아줘서…"
   → 선택지 **[같이 놀자!]** / **[혼내준다]**. '같이 놀자'를 고르면 그르릉이 친구가 되고 분홍 별(사랑)을 돌려준다.
   '혼내준다'를 고르면 그르릉은 보석을 던져주고 엉엉 울며 날아간다. 어느 쪽이든 보석은 얻는다.
5. **별빛 축제 (36달 끝)**: 왕관이 되살아났는지와 능력치에 따라 엔딩.

### 이벤트
- **고정 스토리 이벤트**: 프롤로그, 보스 처치 후 대화, 마왕 탑이 열릴 때, 그르릉의 심술 편지(18달째), 축제 6달 전 알림(30달째)
- **생일 (매년 첫 달)**: 루루가 케이크를 들고 온다. 선물 아이템을 받는다(1년차 꽃 화관, 2년차 하트 목걸이, 3년차 요정 날개).
- **가을 수확제 (매년 10월)**: 대회 하나를 골라 참가. 무술대회(힘+체력) / 요리대회(체력+매력) / 무도회(매력+기품) / 마법대회(마력+지능).
  해당 능력치로 점수를 계산하고 귀여운 라이벌(토토, 미미, 벨라)과 겨룬다. 1등이면 상금과 트로피, 아니면 위로 선물.
- **랜덤 방문 (매달 25%)**: 선택지가 있는 짧은 이야기들
  - 고양이 상인 냥냥이: 특별 상점이 열린다(상점에 없는 희귀 아이템)
  - 길 잃은 강아지 콩이: [집을 찾아준다 → 매력↑] / [간식을 준다 → 콩이가 가끔 놀러옴]
  - 레오 왕자의 다과회 초대: [간다 → 기품↑ 피로↑] / [사양한다]
  - 마녀 할머니 모모: 마법 수프를 준다 → 마력↑ (가끔 맛이 이상해 피로↑)
  - 장난꾸러기 다람쥐가 동전 주머니를 훔쳐감: [쫓아간다 → 힘 체크, 성공 시 돈 되찾고 보너스]
  - 비 오는 날 독서: 지능↑
  - 별똥별 소원: [튼튼해지게 / 똑똑해지게 / 예뻐지게] 중 하나 소폭↑

## 게임 시스템

### 시간
- 1달째 = 1년차 3월(봄), 12살. 36달째 = 3년차 2월, 그 다음이 별빛 축제(엔딩).
- 계절(봄 3~5, 여름 6~8, 가을 9~11, 겨울 12~2)에 따라 방 창밖 풍경과 떠다니는 입자(꽃잎/햇살/낙엽/눈)가 바뀐다.

### 능력치 (0~200, 피로만 0~100)
체력, 힘, 지능, 마력, 매력, 기품, 피로. 그 밖에 돈(G), 레벨, 경험치.
- 시작값: 기본 15 근처 + 캐릭터별 보너스(+10 두 개), 돈 200G
- 화면 표시는 "기본값 (+장비 보너스)". 엔딩 판정은 장비 보너스를 포함한 값.
- 200에 닿으면 막대 옆에 "MAX ✨" 표시, 공부를 고를 때도 이미 최고인 능력치를 알려준다.
- **피로**: 70 이상이면 공부·알바 효과가 절반("너무 피곤해서 집중을 못 했어요…").
  100이 되면 병이 나서 다음 달은 강제로 쉰다(피로 → 30).

- 돈이 모자라면 그 공부는 고를 수 없다(버튼 옆에 "돈이 부족해요").
- 결과 연출: 활동 장면 카드(공주 + 활동 소품 그림) 위로 "하루… 이틀…" 진행 애니메이션 →
  능력치 바가 차오르며 "+6!" 숫자가 톡톡 튄다. 그다음 이벤트 확인, 다음 달로 넘어가며 자동 저장.

### 장비와 상점 (외형 변화)
| 칸 | 아이템 (가격 / 효과) |
|---|---|
| 무기 | 나무검(30G, 공격+3) · 기사의 검(150G, 공격+8) · 별빛 지팡이(160G, 마법+8) · 무지개 활(220G, 공격+6 마법+4) · 하트 성검(보스 보상, 공격+14 마법+6) |
| 옷 | 앞치마 드레스(기본, 방어+1) · 기사 드레스(160G, 방어+6) · 마법사 로브(150G, 방어+3 마력+4) · 무도회 드레스(260G, 방어+2 매력+10) · 별빛 드레스(보스 보상, 방어+10 매력+5 기품+5) |
| 모자 | 꽃 화관(40G, 매력+3) · 마법사 모자(90G, 마력+3) · 은빛 머리장식(100G, 방어+3) · 티아라(200G, 기품+5) |
| 액세서리 | 하트 목걸이(60G, 최대HP+10) · 망토(80G, 방어+2) · 행운의 클로버(120G, 획득 돈+20%) · 요정 날개(180G, 최대MP+10, 도망 성공↑) |
| 소모품 | 물약(20G, HP+30) · 마나 사탕(25G, MP+15) · 큰 물약(60G, HP 전부) |

- 모든 장비는 캐릭터 SVG에 그려진다(옷은 치마·상의·소매 모양 자체가 바뀜). 무기 없음/모자 없음/액세서리 없음도 가능.
- 상점 화면: 진열대 위 아이템 카드 + 오른쪽에 **입어보기 미리보기** 공주. 사면 가방으로.
- 장비 화면: 4칸 슬롯 + 가방 목록, 누르면 바로 장착되고 능력치 변화(+/-)가 초록/빨강으로 표시.
- 냥냥이 특별 상점에서만: 무지개 활, 요정 날개, 큰 물약.

### 무사수행 (모험 보드)
- 지역 4곳: 반짝반짝 숲(처음부터) → 수정 동굴(초록 별 획득 후) → 얼음 성(파란 별 후) → 마왕의 탑(보석 3개 후)
- 지역마다 구불구불한 길 위의 7칸(일반 6칸 + 보스 1칸). 공주 말이 한 칸씩 [앞으로!] 이동.
- 칸 내용(무작위): 전투 55% / 보물상자 20%(돈·물약·가끔 장비) / 요정의 샘 15%(HP·MP 회복) / 꽃밭 10%(매력+1 같은 작은 보너스)
- 언제든 [마을로 돌아가기] 가능. 보스를 이기거나 돌아오거나 지면 그 달이 끝난다.
- 이미 깬 지역 보스를 다시 이기면 보석 대신 돈 보상.

### 전투 (턴제)
- 공주 전투 능력:
  - 최대HP = 30 + 체력 + 레벨×5 + 장비 / 최대MP = 10 + 마력÷2 + 장비
  - 공격력 = 5 + 힘÷2 + 레벨×2 + 장비 / 마법력 = 5 + 마력×0.6 + 장비 / 방어력 = 체력÷5 + 레벨 + 장비
- 명령: **공격** / **마법**(불꽃 MP5 마법력×1.5 피해 · 치유 MP6 HP 회복 · 반짝 별 MP10 마법력×2.5, 마력 40 이상에서 배움) / **물약**(가방의 소모품) / **도망**(일반 60%, 요정 날개 +20%, 보스 불가)
- 피해 = (공격 − 상대 방어÷2) × 0.85~1.15, 최소 1. 10% 확률로 "크리티컬!" ×1.5.
- 승리: 경험치·돈, 레벨업 시 팡파르. 패배: "루루가 공주를 구해서 집으로 데려왔어요" → HP 회복, 그 달 종료. 돈·아이템을 잃지 않는다(아이가 속상하지 않게).
- 연출: 공주 돌진, 적 흔들림·깜빡임, 데미지 숫자 팝업, 마법 반짝이 입자, 보스 등장 시 화면 흔들림·이름 배너.

| 반짝반짝 숲 | 말랑 슬라임, 꽃 토끼, 도토리 다람쥐 | 대왕 버섯 뭉게 |
| 수정 동굴 | 박쥐 박박이, 돌멩이 거북, 수정 게 | 수정 골렘 또각이 |
| 얼음 성 | 눈사람 뭉치, 얼음 요정 링, 펭귄 기사 | 눈의 여왕 프로스티 |
| 마왕의 탑 | 꼬마 유령 부우, 구름 양, 장난감 병정 | 심술 마왕 그르릉 |

지역이 뒤로 갈수록 강해진다. 대략적인 기준: 숲 HP 15~25 / 동굴 35~50 / 얼음 60~80 / 탑 90~120, 보스는 그 3배 정도.
구체적인 수치는 구현 중 플레이하면서 맞춘다(목표: 1년차 말에 숲 보스, 2년차에 동굴·얼음, 3년차에 탑을 깰 수 있게).

## 화면 구성
1. **타이틀**: 성과 하늘 배경, 반짝이 로고, [처음부터] [이어하기(저장 있을 때)] [엔딩 도감] [← 메뉴]
2. **캐릭터 고르기** (시안 ①) → 이름 입력 팝업(기본 이름이 채워져 있음) → 프롤로그
3. **메인(공주의 방)** (시안 ②): 상단 바(날짜·나이·돈·소리), 왼쪽 공주와 루루, 오른쪽 능력치 + 버튼 8개
   (공부 / 아르바이트 / 휴식 / 무사수행 / 상점 / 장비 / 루루와 대화 / 엔딩 도감)
   - 공부·아르바이트·휴식·무사수행 버튼을 누르면 세부 선택 팝업이 열린다
   - 루루와 대화: 지금 상황에 맞는 조언("요즘 피곤해 보여요, 쉬는 건 어때요?", "숲의 보스는 레벨 4쯤이면 이길 수 있어요!")
4. **활동 결과** 연출
5. **대화(이벤트)**: 화면 아래 비주얼노벨식 대화창 + 말하는 인물 초상화, 글자가 한 글자씩 나타남, 선택지 버튼
6. **상점 / 장비**
7. **모험 보드** → **전투** (시안 ③)
8. **엔딩**: 전용 배경 + 공주 + 제목 + 후일담 + 꽃잎, 끝나면 도감에 등록
9. **엔딩 도감**: 12칸, 본 것은 그림과 제목, 못 본 것은 "?" 실루엣과 힌트 한 줄

허브(`index.html`)에 세 번째 카드 "👑 꼬마 공주 키우기 / 공주를 키우고 모험을 떠나요!" 추가.

## 코드 구조

신데렐라와 같은 방식: 빌드 없음, 순수 HTML/CSS/JS(ES 모듈), GitHub Pages에 그대로 올린다.
글꼴은 Google Fonts의 Jua(제목·버튼)와 Gowun Dodum(본문).

```
games/princess/
  index.html            ← 화면 틀 + 글꼴 링크
  style.css             ← 공통 꾸밈(프레임, 리본, 버튼, 바, 애니메이션)
  src/
    main.js             ← 시작, 화면 전환(router)
    state.js            ← 게임 상태, 새 게임, 저장/불러오기, 장비 포함 능력치 계산, 날짜/계절
    rules.js            ← 순수 규칙: 스케줄 적용, 피로·병, 전투 공식, 엔딩 판정 (테스트 대상)
    sound.js            ← 웹오디오 배경음(집/모험/전투/보스/엔딩)과 효과음
    ui.js               ← 공통 UI: 팝업, 토스트, 능력치 증감 숫자, 반짝이
    data/
      characters.js     ← 4명(색, 머리 모양, 시작 보너스, 소개 대사)
      items.js          ← 장비·소모품
      activities.js     ← 공부·알바·휴식 목록
      enemies.js        ← 적 능력치·보상
      regions.js        ← 지역, 해금 조건, 칸 확률
      events.js         ← 스토리·생일·수확제·랜덤 이벤트 (대사 + 선택지 + 효과)
      endings.js        ← 엔딩 조건·문구
    art/
      avatar.js         ← 공주 SVG (머리 모양 4종 × 장비 레이어)
      npcs.js           ← 루루, 냥냥이, 레오 왕자, 모모, 콩이, 그르릉 초상화
      monsters.js       ← 적 16종 SVG
      scenes.js         ← 배경: 방(계절별), 지역 4곳, 엔딩 장면, 활동 장면 소품
    screens/
      title.js  select.js  home.js  activity.js  dialogue.js
      shop.js   equip.js   adventure.js  battle.js  ending.js  gallery.js
tests/princess/
  rules.test.js         ← node --test 로 돌리는 규칙 테스트
```

- **데이터와 그림과 화면을 분리**: 아이템·이벤트·엔딩을 추가할 때는 `data/`만 고치면 된다.
- **rules.js는 화면과 무관한 순수 함수**라서 Node 내장 테스트(`node --test`)로 검사한다:
  스케줄 효과·피로/병, 돈 부족, 능력치 상한(0~100), 장비 보너스 계산, 전투 피해 공식, 레벨업, 엔딩 우선순위.
- 저장: `localStorage` 키 `princess-save-v1`(진행 상황), `princess-endings-v1`(도감). 저장 데이터가 깨졌으면 무시하고 타이틀에서 새로 시작.
- 그림·연출은 매 단계 브라우저에서 직접 확인한다.

## 만드는 순서 (단계마다 브라우저 확인)
1. 틀 + 타이틀 + 캐릭터 고르기 + 공주 SVG(모든 장비 그림) + 메인 방 화면
2. 매달 스케줄 + 결과 연출 + 피로/병 + 계절 + 자동 저장/이어하기
3. 상점 + 장비 화면
4. 모험 보드 + 턴제 전투 + 적 16종
5. 대화 시스템 + 스토리·생일·수확제·랜덤 이벤트 + 보스와 보석 + 마왕 선택지
6. 엔딩 12종 + 엔딩 도감 + 음악·효과음 + 허브 카드 + 밸런스 조정
